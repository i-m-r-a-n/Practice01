# Phase 1 shell reference (superseded)

Kept for the record only. The delivered model is `01_EDITABLE_3D/Final_Office_Interior.blend`, built by
`01_EDITABLE_3D/scripts/build_model.py` from `survey.py` + `office_layout.py`.

| File | What it is |
|---|---|
| `garment_factory_ground_floor_phase1.blend` / `.glb` | phase 1 building shell (walls, openings, stairs) |
| `top_view`, `isometric_view`, `perspective_view` | phase 1 shell views |
| `dimension_schedule.csv` | phase 1 measurement schedule |
| `legacy_scripts/` | the phase 1 / early phase 2 generator scripts; the survey data in them was moved to `scripts/survey.py` |

"A-100" and "A-103" in these files are sheet numbers that were given in the chat to drawings prepared from the client's
sketches. They are not client files. The sources are the client's hand-measured sketches (overview and rooms 4, 5, 6, 7, 8),
the site photos and the master plan PDF (see `04_DOCUMENTATION/design_concept_and_notes.md`, section 1).
