# 15. SME Foundation Loan Checklist

Position in priority: IDLC/bank refinance-er **por** (PRD rule 14).
SME Foundation nije direct loan dey na — **partner bank/NBFI-er through** credit wholesaling program chalay. Current partner list + scheme terms SME Foundation website/office theke confirm korte hobe.

## Step 1 — Research (nije korben, ami draft/checklist debo)

- [ ] SME Foundation-er current credit wholesaling program active kina check (website/phone)
- [ ] Partner bank/NBFI list collect
- [ ] Interest rate + max amount + tenure note korun
- [ ] Cluster/sector requirement ache kina (kono kono program specific sector-er jonno)
- [ ] ADS (proprietorship) vs AFTL (company) — kon entity eligible

## Step 2 — Entity Fit Check

| Question | ADS | AFTL |
|---|---|---|
| Scheme-e proprietorship allowed? | | |
| Scheme-e limited company allowed? | | |
| Sector match (trading/software/e-commerce)? | | |
| Trade license age requirement? | | |

## Step 3 — Standard Document Pack (partner bank confirm korbe)

- [ ] Trade license (valid)
- [ ] TIN + tax return
- [ ] BIN + VAT status
- [ ] Bank statement 12 months
- [ ] Stock/sales/receivable/payable list
- [ ] NID + photos
- [ ] Business profile
- [ ] Guarantor (scheme onujayi)

## Step 4 — Apply

- [ ] Partner bank branch-e contact (draft message: `09-Message-Drafts/`)
- [ ] Scheme-specific form fill
- [ ] File submit + receipt/reference number rakhun
- [ ] Weekly follow-up log

## Notes

- SME Foundation scheme-er rate usually concessional — normal bank rate-er cheye kom hote pare, kintu fund limited + batch-wise. Timing important.
- Scheme details bochor bochor change hoy — **apply-er age latest circular confirm korun.**
