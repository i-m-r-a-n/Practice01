# 17. AFTL Commercial IRC Checklist

Goal: AFTL-ke import-ready banano. **IRC আগে, LC pore.**
Authority: CCI&E (Office of the Chief Controller of Imports & Exports) — OLM (Online Licensing Module) portal.

## Document Checklist

| # | Document | Status | Notes |
|---|---|---|---|
| 1 | Incorporation certificate | ☐ | |
| 2 | MOA/AOA | ☐ | Import/trading object thakte hobe |
| 3 | Form XII | ☐ | |
| 4 | **Updated trade license** | ☐ | Importer/trading activity thakte hobe — expand age korun |
| 5 | Company TIN | ☐ | |
| 6 | BIN/VAT certificate | ☐ | |
| 7 | Chamber membership (e.g., Dhaka Chamber / relevant association) | ☐ | Na thakle age apply — draft letter niche |
| 8 | Bank solvency certificate (BRAC) | ☐ | Draft request letter niche |
| 9 | Board resolution (IRC/import) | ☐ | Draft niche |
| 10 | Directors' passport-size photos | ☐ | |
| 11 | Directors' NID/passport | ☐ | |
| 12 | Tax return acknowledgement | ☐ | Company + possibly directors |
| 13 | OLM application form | ☐ | Portal-e nije fill korben |
| 14 | Fee/challan payment proof | ☐ | IRC category-based fee — portal-e exact amount dekhabe |

**Note:** IRC-r ceiling category (annual import value limit) ache — koto value-r category niben sheta first-year import plan onujayi select korun. Exact category/fee OLM portal-e confirm korun.

## Order of Work

1. Trade license update (importer activity) → age
2. Chamber membership → apply (7–15 din lagte pare)
3. Bank solvency certificate → BRAC branch-e letter din
4. Board resolution sign
5. OLM portal-e registration + application
6. Fee payment + submit
7. Pre-submission checklist (niche) re-check

## Pre-Submission Checklist

- [ ] Trade license activity-te "Importer" ache
- [ ] Address shob document-e same (trade license, BIN, RJSC)
- [ ] TIN/BIN number application-e thik moto lekha
- [ ] Chamber certificate valid
- [ ] Solvency certificate 3 month-er beshi purano na
- [ ] Board resolution letterhead-e, sign+seal soho
