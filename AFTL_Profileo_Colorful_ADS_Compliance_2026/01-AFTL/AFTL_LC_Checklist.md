# 18. AFTL LC / Import Checklist

Precondition: **IRC hoye gele tarpor LC.** (IRC checklist: `AFTL_IRC_Checklist.md`)

## A. Company-side Documents

- [ ] AFTL updated trade license
- [ ] AFTL TIN
- [ ] AFTL BIN
- [ ] AFTL IRC
- [ ] AFTL bank account (BRAC) — active + sufficient margin
- [ ] Board resolution (LC/import) — IRC resolution-er moto, "open letters of credit" wording soho

## B. Per-Shipment Documents

- [ ] Supplier Proforma Invoice (PI) — niche-r PI checklist onujayi
- [ ] HS code (sothik ta — **kokhono wrong HS code na**)
- [ ] Product description, quantity, unit price, total value
- [ ] Country of origin
- [ ] Weight + CBM
- [ ] Shipment method (sea/air)
- [ ] Insurance cover note
- [ ] LCAF (LC Authorization Form) — bank korabe
- [ ] Margin money ready (bank bolbe koto %)
- [ ] C&F agent selected
- [ ] Commercial invoice (shipment-er por)
- [ ] Packing list
- [ ] Bill of lading / airway bill
- [ ] Certificate of origin

## C. PI-te Ki Ki Thakte Hobe (supplier-ke bolben)

1. Supplier full name + address + bank details
2. Buyer: Ahmed Facade Technologies Limited + address
3. Product description + HS code + quantity + unit price + total (currency)
4. Incoterm (FOB/CIF/CFR)
5. Port of loading + destination (Chattogram/Dhaka)
6. Delivery time + validity of PI
7. Payment term: L/C at sight (or as agreed)

## D. Landed Cost Formula (per product)

```
Landed cost = Product cost (invoice)
            + Freight (China → BD)
            + Insurance
            + Customs duty + VAT + AIT + other taxes (HS code onujayi)
            + C&F agent fee + port charges
            + Local transport (port → warehouse)
```

⚠️ Duty/tax exact rate HS code onujayi Bangladesh Customs tariff-e check korun / C&F agent-ke jiggesh korun. **Under-declaration/wrong HS code kokhono na** — ekbar dhorle IRC/bank relationship-e permanent damage.
