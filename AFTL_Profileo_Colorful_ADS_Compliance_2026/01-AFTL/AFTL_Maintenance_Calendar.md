- [ ] AFTL VAT/BIN return check + submit before deadline (VAT return deadline usually month-er 15 tarikh — portal-e confirm)
- [ ] ADS VAT return check (jotodin ADS active)
- [ ] AFTL bank transaction review (BRAC statement)
- [ ] Profileo revenue/expense update (accounting sheet)
- [ ] Colorful Lifestyle sales/stock/expense update
- [ ] ADS compliance/loan status check (jotodin active)
- [ ] Receivable/payable update
- [ ] Document backup (Google Drive/iCloud folder sync)

## 🗓️ Quarterly (Jan/Apr/Jul/Oct)

- [ ] VAT return status audit (3 month-er tracker complete?)

- [ ] Receivable/payable summary

## 🗓️ Yearly — May (trade license season)

- [ ] Business activity update check (notun kono line add lagbe?)
- [ ] Address check (shob document consistent?)
- [ ] DNCC e-trade payment/renewal complete korun **June-er age**

## 🗓️ Yearly — September (tax season)

- [ ] BIN active + return clean?
- [ ] Tax return updated (company + directors)?
- [ ] Bank statement ready (12 months)?
