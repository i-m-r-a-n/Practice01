## ⬜ STEP 4 — Personal Tax Return (Imran, nije, free)

**Portal:** **etaxnbr.gov.bd** (eReturn)

### 4A — Login
1. TIN **315112192747** diye login
2. Password bhule gele "Forgot" → mobile OTP → reset (nije)

### 4B — Return-er data ready korun (agei Excel-e)
- **Business income (ADS):** sales – khoroch = net profit
  - ⚠️ Sob bank deposit income NA। Nijer/family transfer, loan, account-to-account bad din। Shudhu actual customer sale
  - Khoroch: purchase, transport, rent, salary, utility ityadi bad
- **Assets:** bank balance (30 June 2026), AFTL 87% share (~8.7 lakh paid-up), ADS capital, cash, personal jinish
- **Family expense:** yearly honest estimate

### 4C — File
1. eReturn-e assessment year **2026-2027** select (ba jeta due)
2. Ager zero return "revise" korte hole oi year select kore edit
3. Income from Business section-e ADS profit din
4. Assets (IT-10B) + expense (IT-10BB) fill
5. Portal auto tax calculate korbe
6. Submit → acknowledgement download → `Imran_Tax_Return_2026-27.pdf`

**Sazzad-er ta:** same portal, TIN **423585639787**, first return (simple — income kom hole prai zero, kintu asset/info dite hobe)।
